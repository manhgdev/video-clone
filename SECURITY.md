# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 3.x     | :white_check_mark: |
| < 3.0   | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please do not open a public issue. Instead, report it responsibly through one of the following channels:

1. **GitHub Security Advisory**: Open a private advisory under the repository's **Security** tab.
2. **Email**: Contact the primary maintainer directly via GitHub profile: [@manhgdev](https://github.com/manhgdev).

### What to include
- A clear description of the vulnerability.
- Steps or a minimal proof of concept (PoC) to reproduce the issue.
- Potential impact and suggested mitigations, if known.

We will acknowledge receipt within 48 hours and work on a fix promptly.
