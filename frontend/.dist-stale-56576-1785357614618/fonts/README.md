# Bundled caption fonts

These font files are bundled so preview measurement and Pillow export use the
same bytes on every machine. All families are sourced from the
[Google Fonts repository](https://github.com/google/fonts) and distributed
under the SIL Open Font License 1.1. The matching license text is beside this
file for Noto Sans and in `licenses/` for the other families.
